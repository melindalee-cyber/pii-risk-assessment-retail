# PII Risk Assessment - Retail Company

## What I’m learning
This project shows how to identify and protect customer personal data (PII) in a retail system.

---

## What is PII?
PII means Personal Identifiable Information such as:
- Name
- Email
- Address
- Credit card information

---

## PII Inventory

| Data Type | Example | Risk Level |
|------------|--------|------------|
| Name | John Smith | Medium |
| Email | john@email.com | Medium |
| Address | 123 Main St | High |
| Credit Card | 4111-XXXX | High |

---

## Risks Identified
- Data breach from hackers
- Employee misuse of data
- Weak authentication systems
- Unencrypted databases

---

## Security Controls
- Multi-Factor Authentication (MFA)
- Encryption of sensitive data
- Role-Based Access Control (RBAC)
- Logging and monitoring

---

## Frameworks Used
- NIST Cybersecurity Framework
- ISO 27001

---

## What I learned
How organizations classify PII, assess risk, and apply controls to protect customer data.
